| Gemma 3 1B IT | 401 (gated or not public) | not comparable | Cannot download without an authorized Hugging Face login |
| Gemma 3 4B IT | 401 | not comparable | Same |
| Llama 4 Scout 3B | 401 | not comparable | Same. This repo may not exist under this name. |

Sizes also differ. The 0.8B catalog size is 531,248,128 bytes. Hugging Face reports 532,517,120.

Every Qwen download would therefore end in a checksum error. The app's SHA-256 check is working as designed. The catalog values are wrong.

## False or unsupported claims in README, ARCHITECTURE and scope.md

1. Hybrid search with vector RRF, "under 50 ms across thousands of documents". Vector side never runs.
2. "Ed25519 signed catalog manifest". The signature is a SHA-256 digest of ids, hashes and sizes. It has no key and proves no publisher.
3. Chunking "averaging 500 characters with 100-character overlap" (README). Code uses 1500 and 250, which ARCHITECTURE states.
4. Library database at `~/.aiassistant/library.db` (ARCHITECTURE). Code uses `~/.aiassistant/index/library.db`.
5. Tool "executions" trigger approval (README). Tool actions are list, read, write and search. No execution exists.
6. "Immutable" or "append-only" audit log (README, scope). `clear_tool_audits` deletes rows.
7. Keyboard matrix: README says Cmd+2 is Model Manager, Cmd+3 Library, Cmd+4 Memory, Cmd+5 Settings. `App.svelte` maps Cmd+2 to Search, Cmd+3 to Memory, Cmd+4 to Models, Cmd+5 to Settings.
8. "33 passing automated Rust tests" (README). Passes in a clean temp dir, but one test fails in the default temp dir.
9. "SHA-256 verified downloads" as a shipped guarantee. The check runs, but the catalog hashes are wrong, so no Qwen model installs.
10. Model families in scope.md ("Qwen 2.5/3.5 quantized series"). The catalog has Qwen 3.5 plus Gemma 3, Llama 4 Scout and DeepSeek R2.
11. Memory root "user-approved" (scope). Code fixes it at `~/.aiassistant/memory/`.
12. "Typed IPC, zero `serde_json::Value`" (ARCHITECTURE, README). `inference.rs` builds stream event payloads with `serde_json::json!`.
13. "Zero `unwrap`/`expect` in user paths" (README). 16 occurrences in `src-tauri/src`. I did not check which are on user paths.
14. The README quality score (98.25/100) and the scorecard have no run behind them in this audit.
